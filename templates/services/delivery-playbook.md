# Delivery Playbook (creative and automation projects)

## Phases
| Phase | Goal | Key outputs | Exit gate |
|-------|------|-------------|-----------|
| 0 Sign | SOW signed, deposit paid | SOW, invoice | Payment received |
| 1 Onboard | Access, assets, comms set | Onboarding checklist, kickoff notes | All client inputs received or dated |
| 2 Plan | Shared understanding | Spec/brief, project plan | Client approves plan |
| 3 Build / Produce | Make the thing | Workflows or creatives, internal QA notes | Internal QA passed |
| 4 Verify | Prove it works or fits the brand | Test results, brand-gate report, UAT | Client sign-off |
| 5 Deploy / Deliver | Go live or hand over assets | Live workflows, final files | Confirmed working in production |
| 6 Hypercare | Catch early issues | Daily checks, issue log | {{2}} weeks stable |
| 7 Close | Transition to retainer or end | Handover, final invoice, testimonial, lessons | Signed close-out |

## Roles (RACI)
| Task | Delivery lead | Builder/creator | QA | Client approver |
|------|--------------|----------------|-----|-----------------|
| Scope and plan | A/R | C | C | A (approve) |
| Build | A | R | C | I |
| QA/UAT | A | C | R | R (UAT) |
| Change requests | R | C | I | A |

## Communication cadence
Kickoff · weekly status (same day/time) · written recap after every call · single shared channel · decisions logged in the approval log.

## Definition of done (all projects)
- Meets acceptance criteria in the SOW · QA checklist passed · client sign-off recorded · documentation delivered · access and credentials logged · lessons captured.

## Escalation
Blocked >2 business days → delivery lead flags to client approver → founder if unresolved in {{n}} days. Scope creep → change request. Quality concern → pause, fix, tell the client.

## Quality gates
- Creative: brand-gate rubric passed; claims reviewed; music/likeness rights confirmed.
- Automation: test plan passed; error workflow live; runbook written.

## Project economics (update weekly)
Hours planned vs actual · tool/API cost · margin to date · change requests raised/priced.
